# pertemuan-01
1. kesinambungan PWD–DPW–DPWL;
  
jawaban: PWD, DPW, dan DPWL merupakan materi yang saling  
berhubungan. Pada PWD, kita belajar dasar-dasar pemrograman web seperti HTML, CSS, PHP, database, dan CRUD. Setelah memahami dasar tersebut, materi dilanjutkan di DPW dengan membuat aplikasi web yang lebih lengkap.
Kemudian pada DPWL, materi yang sudah dipelajari sebelumnya dikembangkan lagi. Salah satu contohnya adalah penggunaan konsep MVC. Dengan MVC, kode program yang dibuat bisa lebih teratur karena bagian tampilan, proses, dan database dipisahkan.
Jadi, PWD bisa dianggap sebagai dasar untuk belajar web, DPW sebagai tahap pengembangan aplikasi, dan DPWL sebagai tahap lanjutan untuk membuat aplikasi yang lebih terstruktur.

2. perbedaan PHP terstruktur dan MVC
   
jawaban: PHP terstruktur adalah cara membuat program PHP dengan menuliskan kode sesuai dengan kebutuhan program tanpa menggunakan pembagian khusus seperti Model, View, dan Controller. Biasanya kode untuk mengambil data dari database dan menampilkan data bisa berada dalam satu file.
Contohnya, kode PHP bisa langsung digunakan untuk melakukan koneksi database, mengambil data, kemudian menampilkan data tersebut ke halaman.
Sedangkan MVC membagi program menjadi tiga bagian, yaitu Model, View, dan Controller. Ketiga bagian tersebut mempunyai tugas masing-masing.
Perbedaannya, PHP terstruktur lebih sederhana sehingga cocok digunakan untuk program yang tidak terlalu besar. Sedangkan MVC mempunyai struktur yang lebih jelas sehingga lebih cocok digunakan ketika aplikasi sudah memiliki banyak fitur.

3. fungsi Model, View, dan Controller

Jawaban: A. Model
Model digunakan untuk mengatur data dan berhubungan dengan database. Contohnya seperti mengambil data, menambahkan data, mengubah data, dan menghapus data.

B. View
View merupakan bagian yang berhubungan langsung dengan tampilan yang dilihat oleh pengguna. Contohnya halaman login, halaman dashboard, tabel data mahasiswa, dan form input data.

C. Controller
Controller digunakan untuk mengatur jalannya program dan menjadi penghubung antara Model dengan View. Controller menerima request dari pengguna, kemudian menentukan proses apa yang harus dilakukan.

4. alur request–response MVC
   
Jawaban: Alur request dan response pada MVC dimulai ketika pengguna melakukan sesuatu pada website, misalnya membuka halaman data mahasiswa.

Pertama, pengguna mengirim request melalui browser. Request tersebut diterima oleh Controller. Setelah itu Controller meminta data yang diperlukan kepada Model.

Model kemudian mengambil data dari database. Setelah data berhasil didapatkan, data dikembalikan ke Controller.

Selanjutnya Controller mengirim data tersebut ke View. View kemudian menampilkan data dalam bentuk halaman yang bisa dilihat oleh pengguna.

5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan; dan

Jawaban: Model digunakan untuk mengatur data mahasiswa yang ada di database, seperti menambah, mengedit, menampilkan, dan menghapus data.

Controller digunakan untuk mengatur proses dari fitur tersebut. Misalnya saat pengguna ingin menambah atau menghapus data mahasiswa.

View digunakan untuk menampilkan data kepada pengguna, seperti tabel data mahasiswa dan form untuk memasukkan data.

6. kesimpulan P1.

Jawaban: PWD, DPW, dan DPWL saling berhubungan dalam pembelajaran pemrograman web. Materi dasar dari PWD digunakan untuk membuat aplikasi di DPW, kemudian dikembangkan lagi di DPWL dengan konsep seperti MVC.

PHP terstruktur lebih sederhana, sedangkan MVC membagi program menjadi Model, View, dan Controller agar lebih rapi. Model mengurus data, View mengurus tampilan, dan Controller mengatur prosesnya.

Dengan MVC, program jadi lebih teratur, mudah dipahami, dan lebih gampang dikembangkan atau diperbaiki.
